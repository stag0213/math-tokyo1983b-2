# 傾いた平面の勾配ビューア（東京大学入試問題　1983年度文科）

最も急な方向の勾配と南北方向の勾配から、東西方向の勾配を求める問題を可視化する Web アプリです。

斜面と各方向の上りを立体図で表示します。スライダーや方向の切り替えを操作しながら、勾配の関係を直角三角形でも確認できます。

**問題と答え:**

> 傾いた平面上で、最も急な方向の勾配が 1/3 である。南北方向の勾配を測ったところ 1/5 であった。このとき、東西方向の勾配はどれだけか。

東西方向の勾配の**大きさは 4/15**、小数では約 0.267 です。

問題文だけでは東と西のどちらが上りかは決まらないため、東向きに測った符号付き勾配は +4/15 または −4/15 となります。

**起動方法:**

1. アプリ本体を `index.html` という名前で保存します。
2. `index.html` をブラウザで開きます。
3. 図やスライダーを操作して、勾配の変化を確認します。

インストール、ビルド、ローカルサーバーの起動、インターネット接続は不要です。

**操作方法:**

| 操作 | 内容 |
| --- | --- |
| 立体図をドラッグ | 斜面を見る視点を回転します。 |
| 最急勾配のスライダー | 最も急な方向の勾配の大きさを変更します。 |
| 南北方向の勾配のスライダー | 南北方向の勾配の大きさを変更します。上限は最急勾配です。 |
| 東西方向の上り | 東と西のどちらが上りかを切り替えます。 |
| 南北方向の上り | 北と南のどちらが上りかを切り替えます。 |
| 問題の条件に戻す | 勾配と上り方向を初期状態に戻します。 |
| 視点を戻す | 立体図の視点を初期状態に戻します。 |

立体図の矢印は、紫が最も急な上り、青が南北方向の上り、オレンジが東西方向の上りを表します。

**数学的な考え方:**

東向きを x 軸、北向きを y 軸の正の方向とし、平面の高さを次のように表します。

$$
z=ax+by
$$

ここで a は東向きの勾配、b は北向きの勾配です。水平面上の勾配ベクトルは次のようになります。

$$
\nabla z=(a,b)
$$

最も急な方向の勾配の大きさは、このベクトルの大きさです。したがって、最急勾配を g とすると、次の関係が成り立ちます。

$$
g=\sqrt{a^2+b^2}
$$

問題の条件を代入し、東西方向の勾配の大きさを求めます。

$$
|a|
=\sqrt{\left(\frac{1}{3}\right)^2-\left(\frac{1}{5}\right)^2}
=\sqrt{\frac{16}{225}}
=\frac{4}{15}
$$

アプリの直角三角形は、水平面上の勾配ベクトルの成分を表しています。立体図で斜面上に描かれた東西・南北の矢印自体が直角をなすという意味ではありません。

**表示について:**

問題の条件では、東西方向の勾配を分数の 4/15 と小数の近似値で表示します。条件を変更した場合、数値は見やすいように小数第3位に丸めて表示されます。

南北方向の勾配は最急勾配を超えられません。最急勾配を下げて南北方向の勾配より小さくなった場合は、南北方向の値も上限に合わせて調整されます。

**動作環境:**

Canvas とポインターイベントに対応した、最近の Web ブラウザを使用してください。外部ライブラリは不要です。スマートフォンやタブレットでは、図をタッチして視点を回転できます。
